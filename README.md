## Descripción

## Requisitos 

- Asegúrese de tener instalado Docker Desktop.
- Clone el repositorio en su ordenador, en este caso haciendo uso de git bash ejecute (git clone https://github.com/SELF-Software-Evolution-Lab/gitsigth.git)
- Una vez realizado lo anterior, desde su terminal ubiquese en el directorio que contiene todos los archivos de gitsight.
  Ejemplo:
     - cd Downloads\gitsigth-main-docker\gitsigth-main
       
- Finalmente, ejecute el siguiente comando:
  - docker compose up

- Una vez se finalice el proceso que desencadena el comando anterior, se podrá acceder a la herramienta desde el navegador.
    - Homepage URL: http://localhost:8000
